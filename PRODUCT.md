# Product

## Users

Someone mid-task who needs to jot a thought without leaving what they are
doing: summon noted with a keypress, write, dismiss.

## Purpose

A scratchpad one keypress away. It opens instantly, writes like a plain text
editor with light markdown (lists, tasks, headings), and saves notes as plain
markdown files on disk.

## Not

- Not a knowledge base: no sync, accounts, backlinks or graph.
- Not a rich-text editor: the file on disk is always the plain markdown typed.

## Platform

macOS and Linux (Wayland first).
